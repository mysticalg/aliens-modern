# THE HIVE — Modern Edition
Three.js remake of the PS1-style [The Hive](https://mysticalg.github.io/aliens-ps1-game/). Play: https://mysticalg.github.io/aliens-modern/
Desktop: WASD + mouse, click/Space fire, Q swap, Shift sprint. Phone: portrait touch controls. `?all` unlocks every chapter, `?q=low|medium|high` quality, `?auto` autopilot (testing).
